# iLab — Geometry of Intelligence

[iLab’s canonical research wiki](https://iontlab.org/) is the human-readable home for research framing, ontology, definitions, mathematical development, conjectures, reading notes, status, and roadmap.

This public repository is the wiki’s technical / artifact companion. It is intended to hold executable and formalization artifacts, testbed code, source-controlled implementation material, and related technical documentation when those artifacts exist.

The project is early-stage. This repository currently contains only this README; no Lean proofs, Agda developments, or executable testbeds are present. Mathematical and formal material is developed only after study and validation. A scaffold reserves a place for future work and does not establish a result.

**Scaffold now → learn → validate → promote.**

The wiki remains the canonical research space. This repository does not duplicate the wiki, and no automatic synchronization or proof-assistant infrastructure is established.
