# Mathematics Learning — non-exercise ordinary category theory

Technical companion to the [Synthetic Category Theory learning project](https://iontlab.org/doku.php?id=mathematics_learning:higher_category_theory:synthetic_category_theory:start). The existing eight DokuWiki lessons remain the canonical educational exposition. The single Lake project and pinned Lean/Mathlib versions are unchanged.

The binding source is the supplied 13-page *Lecture Notes: Synthetic Category Theory* by Lyne Moser and Tashi Walde. Supplementary books clarify conventions only. The source PDFs and complete extracted texts are not published. The exposition is independently written with AI assistance; exact-primary republication authorization and an official public URL remain unverified.

The nine modules under `ILab.MathematicsLearning` cover non-exercise ordinary definitions, examples, laws, equivalences and explicitly scoped foundational formulations. [Verification](verification/VERIFICATION.md) records 225 compiled / 116 authored declarations, their exact assumptions and Mathlib provenance. [The obligation inventory](../../docs/mathematics-learning/obligations.json) covers all 58 source items, with exercises withheld and five higher-foundation/model obligations recorded explicitly.
