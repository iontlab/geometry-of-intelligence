==== 1.4. Natural transformations between functors ====

==== Definition 1.20. ====

Given functors \(F,G:\mathcal C\to\mathcal D\) between strict categories, a **natural transformation** \(\alpha:F\Rightarrow G\) consists of:

  * for each object \(x\in\mathcal C\), a morphism \(\alpha_x:Fx\to Gx\) in \(\mathcal D\), called the **component** of \(\alpha\) at \(x\);

satisfying the following axiom:

  * \(\alpha\) is natural: for each morphism \(f:x\to y\) in \(\mathcal C\), the following square commutes

i.e., \(Gf\circ\alpha_x=\alpha_y\circ Ff\).

==== Construction 1.21. ====

Let \(\mathcal C\) be a locally small strict category and \(f:c\to d\) be a morphism in \(\mathcal C\). There is a natural transformation

$$\mathcal C(-,f):\mathcal C(-,c)\Rightarrow\mathcal C(-,d)$$

whose component at an object \(x\in\mathcal C\) is the function

$$f_*:\mathcal C(x,c)\to\mathcal C(x,d),\quad(g:x\to c)\mapsto(fg:x\to d).$$

This is well-defined (Exercise).

==== Definition 1.22. ====

Given functors \(F,G:\mathcal C\to\mathcal D\) between strict categories, a natural transformation \(\alpha:F\Rightarrow G\) is a **natural isomorphism** if, for each object \(x\in\mathcal C\), its component \(\alpha_x:Fx\to Gx\) is an isomorphism in \(\mathcal D\).

We sometimes say that, for all objects \(x\in\mathcal C\), there is an isomorphism \(Fx\cong Gx\) which is **natural** in \(x\).

==== Construction 1.23. ====

Given strict categories \(\mathcal C\) and \(\mathcal D\), there is a strict category \(\operatorname{Fun}(\mathcal C,\mathcal D)\), called the **functor strict category**, with

  * object set \(\operatorname{Ob}(\operatorname{Fun}(\mathcal C,\mathcal D)):=\mathcal{CAT}_s(\mathcal C,\mathcal D)\) consisting of the functors \(\mathcal C\to\mathcal D\);
  * for all objects \(F,G\in\operatorname{Fun}(\mathcal C,\mathcal D)\), hom set \(\operatorname{Fun}(\mathcal C,\mathcal D)(F,G)\) consisting of the natural transformations \(F\Rightarrow G\);
  * for each object \(F\in\operatorname{Fun}(\mathcal C,\mathcal D)\), **identity natural transformation** \(\operatorname{id}_F:F\Rightarrow F\) having component at an object \(c\in\mathcal C\) given by

$$(\operatorname{id}_F)_c:=\operatorname{id}_{Fc}:Fc\to Fc;$$

  * for all morphisms \(\alpha:F\to G\) and \(\beta:G\to H\) in \(\operatorname{Fun}(\mathcal C,\mathcal D)\), **composite natural transformation** \(\beta\circ\alpha:F\Rightarrow H\) having component at an object \(c\in\mathcal C\) given by the composite

$$(\beta\circ\alpha)_c:=\beta_c\circ\alpha_c:Fc\to Hc.$$

This is a well-defined strict category (Exercise).

==== Proposition 1.24. ====

//Given strict categories \(\mathcal C\) and \(\mathcal D\), a natural transformation is an isomorphism in \(\operatorname{Fun}(\mathcal C,\mathcal D)\) if and only if it is a natural isomorphism.//

//Proof.// Exercise. \(\square\)

==== Construction 1.25. ====

The **terminal strict category** is the strict category \([0]\) with a single object \(*\) and a single morphism \(\operatorname{id}_*\).

==== Proposition 1.26. ====

//Given a strict category \(\mathcal C\), there is an isomorphism of strict categories//

$$\operatorname{Fun}([0],\mathcal C)\cong\mathcal C$$

//which is natural in \(\mathcal C\).//

//Proof.// Exercise. \(\square\)

==== Remark 1.27. ====

As a consequence of this result, we have that an object \(c\in\mathcal C\) corresponds to a unique functor \(c:[0]\to\mathcal C\), which we also call \(c\).

==== Construction 1.28. ====

Given a functor \(F:\mathcal C\to\mathcal D\) between strict categories and a strict category \(\mathcal E\), there is a functor

$$F^*:\operatorname{Fun}(\mathcal D,\mathcal E)\to\operatorname{Fun}(\mathcal C,\mathcal E),$$

called the **precomposition functor** with \(F\), sending

  * a functor \(G:\mathcal D\to\mathcal E\) to the composite \(GF:\mathcal C\to\mathcal E\);
  * a natural transformation \(\alpha:G\Rightarrow H\) between functors \(G,H:\mathcal D\to\mathcal E\) to the natural transformation \(\alpha F:GF\Rightarrow HF\) whose component at an object \(x\in\mathcal C\) is the morphism in \(\mathcal E\)

$$\alpha_{Fx}:G(Fx)\to H(Fx).$$

There is also a functor

$$F_*:\operatorname{Fun}(\mathcal E,\mathcal C)\to\operatorname{Fun}(\mathcal E,\mathcal D),$$

called the **postcomposition functor** with \(F\), sending

  * a functor \(G:\mathcal E\to\mathcal C\) to the composite \(FG:\mathcal E\to\mathcal D\);
  * a natural transformation \(\alpha:G\Rightarrow H\) between functors \(G,H:\mathcal E\to\mathcal C\) to the natural transformation \(F\alpha:FG\Rightarrow FH\) whose component at an object \(x\in\mathcal E\) is the morphism in \(\mathcal D\)

$$F(\alpha_x):F(Gx)\to F(Hx).$$

These are well-defined functors (Exercise).
