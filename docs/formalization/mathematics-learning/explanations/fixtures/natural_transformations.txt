===== Story / Fairy Tale =====

Two translators, Fern and Gale, send Mira's route book into the same kingdom. Mira places a comparison permit from Fern's version of each town to Gale's version. She insists on a test for every original route: translating with Fern and then comparing must agree with comparing first and then using Gale's translation.

A natural transformation compares two functors through components that satisfy the same compatibility requirement for every arrow. This story explains the definition; the assigned composition and inverse checks are left to the reader.

**Story key:** translators are functors; comparison permits are components; the route test is naturality. **Where the analogy stops:** components are generally not invertible. Choosing a comparison independently at every town is insufficient: every arrow must satisfy the square.

===== Plain Language =====

Naturality says that a comparison respects all the structure-changing maps in the source category. It is stronger than having similarly shaped objects or an arbitrary component at each object.

For an independent example on sets, fix two marker sets \(A,B\) and a function \(q:A\to B\). The maps \(X\times A\to X\times B\), \((x,a)\mapsto(x,q(a))\), form a natural transformation between product functors. For \(f:X\to Y\), either route sends \((x,a)\) to \((f(x),q(a))\). A transformation need not be invertible: a constant \(q\) can collapse two markers. The essential point is compatibility, not reversibility.

===== Mathematics =====

==== Definition 1.20 ====

For \(F,G:C\to D\), a natural transformation \(\alpha:F\Rightarrow G\) assigns \(\alpha_x:Fx\to Gx\) with

$$G(f)\circ\alpha_x=\alpha_y\circ F(f)\qquad(f:x\to y).$$

Both composites have domain \(Fx\) and codomain \(Gy\). The commuting square is

$$\begin{array}{ccc}Fx&\xrightarrow{\alpha_x}&Gx\\ {\scriptstyle Ff}\downarrow&&\downarrow{\scriptstyle Gf}\\ Fy&\xrightarrow{\alpha_y}&Gy.\end{array}$$

==== Construction 1.21 ====

For \(f:c\to d\), the transformation \(h_f:h_c\Rightarrow h_d\) has component \(C(x,c)\to C(x,d)\), sending \(g\) to \(fg\). **Its well-definedness is assigned as an exercise (p. 8); the solution is withheld.**

==== Definition 1.22 ====

A natural transformation is a natural isomorphism when every component is an isomorphism.

==== Construction 1.23 ====

In \(\mathrm{Fun}(C,D)\), objects are functors and arrows are natural transformations. The identity has components \(1_{Fx}\); composition has \((\beta\alpha)_x=\beta_x\alpha_x\). **The well-definedness and category-law checks are assigned as an exercise (p. 8); solutions are withheld.**

==== Proposition 1.24 ====

A natural transformation is an isomorphism in \(\mathrm{Fun}(C,D)\) if and only if it is a natural isomorphism. **Assigned proof (p. 8): solution withheld.**

==== Construction 1.25 ====

The terminal strict category \([0]\) has one object \(*\) and only its identity morphism.

==== Proposition 1.26 ====

For a strict category \(C\), there is an isomorphism of strict categories \(\mathrm{Fun}([0],C)\cong C\), natural in \(C\). **The source says “Proof. Exercise.” (p. 8). The proof, including the naturality check, is intentionally withheld.**

==== Remark 1.27 ====

As a consequence, an object \(c\in C\) corresponds to a unique functor \(c:[0]\to C\), also denoted \(c\).

==== Construction 1.28 ====

For \(F:C\to D\), precomposition gives \(F^*:\mathrm{Fun}(D,E)\to\mathrm{Fun}(C,E)\), with \(G\mapsto GF\) and components \(\alpha_{Fx}\). Postcomposition gives \(F_*:\mathrm{Fun}(E,C)\to\mathrm{Fun}(E,D)\), with \(G\mapsto FG\) and components \(F(\alpha_x)\). **The checks that these are well-defined functors are assigned as an exercise (p. 9); solutions are withheld.**
